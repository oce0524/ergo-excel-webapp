============================================
 엑셀 누적 데이터베이스 웹앱 - 사용법
============================================

■ 하는 일
  - 판매(이카운트) / 재고(이지어드민) 엑셀을 '각각 따로' 업로드
  - 캘린더에서 '기준일자'를 고른 뒤 저장
  - SQLite 데이터베이스(누적데이터.db)에 계속 누적 저장
  - 같은 날짜를 다시 올릴 때 '누적 추가' 또는 '교체' 선택 가능

■ 실행 방법
  1) '실행.bat' 더블클릭
  2) 잠시 뒤 기본 브라우저에 웹앱이 자동으로 열립니다.
     (수동 접속: http://localhost:8501)
  3) 종료하려면 함께 뜬 검은 명령창을 닫으세요.

■ 사용 순서
  [판매 업로드] 탭
    1) 📅 기준일자를 캘린더에서 선택
    2) 저장 방식 선택 (누적 추가 / 같은 기준일자 교체)
    3) 판매 엑셀(.xlsx) 업로드 → 미리보기 확인
    4) [💾 저장(누적)] 클릭 → DB에 쌓임

  [재고 업로드] 탭 : 위와 동일하게 재고 엑셀 업로드

  [전체 요약] 탭 : 판매/재고 누적 행수·기준일자 개수 확인

■ 데이터 확인 / 내보내기
  - 각 탭의 '누적 현황'에서 기준일자별 행수 확인
  - '전체 누적 데이터 보기 / 다운로드'에서 엑셀로 내려받기
  - '특정 기준일자 삭제'로 잘못 올린 날짜 데이터 삭제 가능

■ 데이터베이스 파일
  - 누적데이터.db (앱 폴더 안, SQLite 형식)
  - 이 파일을 지우면 누적 데이터가 모두 초기화됩니다.
  - 백업하려면 이 파일을 복사해 두세요.

■ 참고
  - 판매 파일은 1행이 회사명(제목)이고 2행이 헤더라도 자동 인식합니다.
  - 헤더 위치/공백은 프로그램이 자동으로 처리합니다.
  - 파일 형식(열 구성)이 기존과 다르면 저장이 실패할 수 있습니다.
